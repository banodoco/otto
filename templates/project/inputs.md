## Planning evidence

A compact record for a new project's decision. A draft may record pending evidence and the next action; do not invent sources or approval.

**Scope decision:** Pending — The owner has not selected an end state. Next: present meaningful alternatives and record the actual decision.

**Prior art:** Pending — Relevant existing work has not been inspected. Next: trace current behavior and record source identities, reuse opportunities and meaningful negative findings.

**Approach:** Pending — The approach has not been selected. Next: compare alternatives and identify the smallest complete approach.

**Challenge:** Pending — Consequence and risk are not yet clear. Next: obtain an independent simplification critique if warranted, or explain why it would add little.

**Proof and limits:** Pending — Acceptance evidence is not yet known. Next: specify observable results, meaningful failure cases and unresolved assumptions.

**Review rounds:** Pending — Recommend a number suited to the work and say why. Next: record the owner's decision.

**Run start:** Pending — No run is authorized. Next: record the actual start decision, scope, accountable session, permissions, limits and advisor if there is one.

## Owner decisions

Record each unresolved decision with options and a recommendation, then the date and actual choice when decided. If there are none, write None and retain the heading.

## Source identities

Before implementation, record the actual source identities, revisions, retained changes, dependencies and intended integration destination. Distinguish historical snapshots from current source.

## References

Link supporting research, review notes and actual decisions where useful. Keep credentials, private logs and machine-specific data out of shared records.
